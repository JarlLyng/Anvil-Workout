# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Summary

Be respectful. Assume good faith. Focus on the work, not the person. The maintainer may remove
comments, commits, code, issues and other contributions that don't meet that standard.

## Reporting

Report concerns to **support@iamjarl.com**. Reports are confidential. You'll get a reply within 7
days, and confirmed violations will be acted on.

## Scope

This applies in every project space (issues, pull requests, commit messages and any community
space representing the project) and whenever someone is officially representing the project in
public.
