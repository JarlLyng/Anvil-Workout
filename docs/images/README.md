Mood/atmosphere photography for the marketing site (e.g. gym, barbells, training).

- Format: .webp preferred, else .jpg (photos — not .png).

- Size: max ~2000px wide, compressed to roughly <300 KB each.
- Reference from HTML as: src="images/your-file.jpg"
